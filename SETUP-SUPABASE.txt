إعداد Supabase لموقع AstraMind (10 دقائق، مجاني)

1) supabase.com ← New project (اختر منطقة قريبة: Frankfurt أو Paris) واحفظ كلمة سر قاعدة البيانات.
2) افتح supabase/schema.sql وغيّر REPLACE_WITH_ADMIN_EMAIL إلى بريدك (في موضع واحد فقط داخل is_admin())
   ← SQL Editor ← الصقه كاملاً ← Run (مرة واحدة). هذا ينشئ: جدول الطلبات، محتوى الموقع، مخزن الصور، والإشعارات الفورية، وكل سياسات الحماية.
3) Authentication ← Users ← Add user: نفس البريد + كلمة سر قوية + فعّل Auto Confirm User.
4) Authentication ← Sign In / Providers: عطّل «Allow new users to sign up».
5) Project Settings ← API Keys: انسخ Project URL و Publishable key (يبدأ بـ sb_publishable_)
   وضعهما في public/supabase-config.js (انزع علامات التعليق وعدّل القيم).
   لا تضع secret أو service_role هناك أبداً.
6) انشر الموقع (يُفضَّل Netlify: ارفع المشروع إلى GitHub ثم Add new site ← Import).
7) جرّب: قدّم طلب انضمام من الصفحة الرئيسية، ثم افتح /admin.html وسجّل الدخول ← «طلبات الانضمام».
   وفي «الورشات والفعاليات» عدّل ثم اضغط «🚀 نشر الآن»: يتغيّر الموقع فوراً للزوار.

كيف يعمل:
- الورشات والإعلان والمعرض والتواصل تُحفظ في Supabase وتظهر للزوار فور النشر (الملف public/data.js يبقى نسخة احتياطية افتراضية).
- الصور تُرفع تلقائياً إلى مخزن media. وحذف صورة من اللوحة لا يحذف ملفها من المخزن (يمكنك تنظيفه من Storage عند الحاجة).
- طلبات الانضمام: طلب واحد لكل بريد. تصلك فورياً داخل اللوحة المفتوحة مع صوت وإشعار، ويمكنك قبولها أو رفضها أو تصديرها CSV.

الحماية المفعّلة:
- RLS: الزائر يضيف طلباً فقط (أعمدة محددة)، ولا يقرأ ولا يعدّل ولا يحذف. صاحب الصلاحية الوحيد هو بريد is_admin().
- قيود في القاعدة: أطوال الحقول، صيغة البريد، الموافقة إجبارية، حالات محددة، وطلب واحد لكل بريد.
- الموقع: حقل فخ للبوتات، انتظار دقيقة بين الطلبات، وتنظيف كل نص يأتي من القاعدة قبل عرضه (روابط javascript: مرفوضة).
- اللوحة: تسجيل دخول حقيقي، وعرض نصوص الزوار كنص آمن، وتصدير CSV محمي من حقن الصيغ، و noindex.
- public/_headers (Netlify وCloudflare Pages): CSP ومنع التضمين في إطارات وغيرها. لا يعمل على GitHub Pages.
- أمور تبقى عليك: كلمة سر قوية لحساب المشرف، وحفظ مفتاح secret بعيداً عن الموقع، وللحماية الأقوى ضد البوتات أضف Cloudflare Turnstile لاحقاً.
